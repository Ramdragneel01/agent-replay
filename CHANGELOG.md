# Changelog

## [0.1.0] - 2026-05-04

### Added
- FastAPI service for run creation, event recording, replay and timeline retrieval.
- Deterministic replay engine with deep-merge state patches and reverse playback.
- Browser UI for timeline scrubbing and demo run seeding.
- Prometheus metrics and operational endpoints.
- Test suite covering store, replay engine, and API workflows.
- Docker, compose, and CI pipeline with container smoke checks.
